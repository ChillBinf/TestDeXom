# TestDeXom

Đây là dự án website được xây dựng bằng HTML và CSS.

## Giới thiệu
Website được tạo ra nhằm thực hành kiến thức lập trình web cơ bản.

## Công nghệ sử dụng
- HTML
- CSS

## Cách chạy dự án
1. Clone repository về máy.
2. Mở thư mục dự án bằng VS Code.
3. Mở file `index.html` bằng trình duyệt.
